# GitHub Kaynak Rehberi

Yazılım, tasarım, yapay zekâ ve dijital üretim süreçlerinde kullanılabilecek GitHub projelerini tek yerde topluyorum.

Amacım; bir aracı ararken yalnızca adına değil, ne işe yaradığına ve hangi teknolojiyle çalıştığına da kolayca ulaşabilmek. Bu rehberde uygulamalar, kütüphaneler, AI ajanları, otomasyon araçları, eğitim kaynakları ve beceri koleksiyonları bulunuyor.

**Listede 222 farklı repo bulunuyor.** Aynı proje birden fazla kez eklenmedi; bilinen eski adresler güncel kayıtlarla birleştirildi.

## Liste nasıl okunmalı?

| Sütun | Açıklama |
|---|---|
| No | Kayıt numarası; kategoriler arasında taşınsa da korunur. Sayısal sıralama kategori içinde artar. |
| Repo adı | Projenin GitHub adresine bağlantı. |
| Ne işe yarar? | Projenin kullanım amacının kısa Türkçe özeti. |
| Yayıncı | GitHub depo sahibi olan kullanıcı veya organizasyon. |
| Platform / teknoloji | Temel dil, teknoloji veya kaynak türü; tam bağımlılık listesi değildir. |

Açıklamalar proje tanıtımları temel alınarak özetlendi. Bütün projeler kurulup test edilmedi. Listeye eklenmek, bir proje için kalite veya güvenlik garantisi anlamına gelmez. Yıldız sayıları ve sürekli değişen istatistikler listeye dahil edilmedi.

## Katkıda bulunmak

Yeni bir repo önermek, hatalı açıklamayı düzeltmek veya değişen adresi bildirmek için issue açabilir ya da pull request gönderebilirsiniz.

Yeni kayıt eklerken:

1. Projenin mevcut listede bulunmadığını kontrol edin. Eski adları ve taşınmış adresleri de dikkate alın.
2. Doğrudan proje deposuna bağlantı verin.
3. Ne işe yaradığını kısa ve anlaşılır Türkçeyle açıklayın.
4. Depo sahibini ve temel teknolojisini belirtin.
5. Doğrulanmamış başarı, hız, ücretsiz kullanım veya resmi ortaklık iddiaları eklemeyin.
6. Repoyu baskın işlevine göre tek bir kategoriye ekleyin. Mevcut kayıt numaralarını koruyun; yeni kayda rehberdeki en büyük numaradan bir sonrasını verin.
7. İlgili kategorinin repo sayısını ve rehberin toplam repo sayısını güncelleyin. Yeni kategori gerekiyorsa hızlı erişim tablosuna da ekleyin.

Satır biçimi:

```markdown
| No | [sahip/repo](https://github.com/sahip/repo) | Kısa Türkçe açıklama. | sahip | Dil / teknoloji |
```
